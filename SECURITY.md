# Security Policy

## Reporting a vulnerability

If you find a security problem in this status page, report it privately rather than in a public
issue, through GitHub's
[private vulnerability reporting](https://github.com/sunbrolynk/abm-status/security/advisories/new):
the repo's Security tab, then "Report a vulnerability".

A problem in AudioBook Manager itself belongs in its own repo, and one in UptimeFlare upstream at
[lyc8503/UptimeFlare](https://github.com/lyc8503/UptimeFlare). I'll acknowledge the report as soon
as I can and work on a fix with you before anything is disclosed publicly.
